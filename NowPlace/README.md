
# NowPlace — Projeto Integrador SA2

## Sobre o projeto

O NowPlace é uma aplicação web desenvolvida para a atividade de Programação Front-End, proposta pela professora Andreza Quintas.

O projeto permite que usuários compartilhem momentos, registrando duas fotografias (ambiente e selfie), sua localização e o que estão fazendo.

## Integrantes

- Pietro
- Victor

## Funcionalidades

- Identificação do usuário.
- Captura de fotos do ambiente e selfie.
- Obtenção automática da localização.
- Publicação de momentos (Nows).
- Visualização de publicações próximas.
- Busca por raio de distância.
- Liberação do feed por 24 horas.
- Troca de fotografias com Drag and Drop.
- Armazenamento das publicações no navegador.

## 🌐 APIs utilizadas

### JSONPlaceholder
https://jsonplaceholder.typicode.com

Utilizada para realizar requisições GET e POST.

### OpenStreetMap (Nominatim)
https://nominatim.openstreetmap.org

Utilizada para transformar as coordenadas em um endereço legível.

## Observações

O projeto foi desenvolvido somente com Front-End.

As publicações ficam armazenadas no navegador. A API JSONPlaceholder é utilizada para testes e não compartilha publicações entre dispositivos.
